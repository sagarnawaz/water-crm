# Decisions

## Confirmed by the owner (20 Nov 2026)
| Topic | Decision |
|---|---|
| Language | English UI at launch |
| Pricing | Price per bottle is set **per floor**; a customer can have a custom price; no separate delivery charge |
| Packages / discounts | None |
| Login | Phone number + password; we create the accounts, so no SMS cost |
| Empty bottles | Counted: empties collected on each entry, and bottles at each customer's home |
| Monthly payments | A monthly customer's payment is marked for a month; each month shows bill, paid and left |
| Same-day deliveries | Each delivery is a separate entry; several per day are allowed |
| Bottle deposit | None; bottles are counted only, no money deposit |

## Product defaults (change only with owner approval)
| Topic | Default |
|---|---|
| Money | Whole rupees only |
| Payments | Not tied to single entries; overpayment becomes an advance |
| Users | Only the owner logs in; riders are a payment method, not users |
| Onboarding | We create each business and owner account by hand |
| Offline | View only; saving needs internet in Phase 1 |

## Still open
- **Pricing for other businesses:** subscription price and billing for the SaaS. Not needed for the first supplier.
